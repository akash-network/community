## Meeting Notes

### Oracle & Pyth Updates

* Artur shared ongoing improvements to the Oracle price feed supporting the Akash Network.
* Pyth was recently migrated from **Wormhole Guardians to Pyth routers**, with the new setup functioning well so far.
* A router-set rotation had to be performed manually following a smart contract issue.
* A smart contract fix is planned so future router-set rotations can happen automatically.

### Backup Price Feed

* The team has completed a specification for a backup price feed using validator extensions.
* Each validator would run a sidecar that retrieves prices from multiple aggregators, such as Kraken and CoinGecko, and submits the data alongside validator votes.
* The Oracle module would aggregate these submissions into a backup price feed.
* This provides additional resilience if Pyth experiences problems, allowing the network's pricing mechanism to continue functioning.

### Lease Resizing

* The Core team is working on marketplace improvements that would allow users and providers to negotiate changes to active lease resources.
* Users could resize resources such as **CPU, memory, and GPUs** while keeping their workload on the same provider.
* The goal is to allow compute resources to be adjusted without shutting down the existing lease.

### Governance & Community

* Tyler thanked validators who made themselves available to expedite the recent governance proposal.
* Community members were encouraged to submit future SIG Chain topics through the SIG Chain Discord channel, while validators can also use the validators channel.
* Additional governance proposals are expected as Core team work is completed and roadmap initiatives progress.
