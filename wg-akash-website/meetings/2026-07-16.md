## Meeting Notes

### Website Updates

* Regular website and documentation updates continued across the Akash homepage, ecosystem pages, and roadmap.
* The $100 GPU credit promotion for new Console users ended due to high demand.
* The homepage was simplified to communicate Akash’s GPU value proposition more clearly.
* Ecosystem links were updated, while roadmap changes continued to publish automatically through GitHub Actions.
* Three documentation-related pull requests remained under review.

### Console Documentation

* Tyler highlighted that documentation must reflect the separation between Akash Console and Console Air.
* Existing onboarding guides contain outdated copy and screenshots and do not clearly explain which product users should choose.
* Rodri prepared a screenshot-based onboarding guide, while Max was also updating the Console onboarding flow.
* The team aimed to publish improved documentation before the Akash-sponsored hackathon.
* Piyush agreed to review the structure, screenshots, and relevant pull requests.
* Joe agreed to follow up with Rodri and prepare an additional guide for the main Console experience.

### New Website Pages

* Joe proposed a dedicated GPU page showing the different GPU models available on Akash.
* He also proposed an enterprise page covering managed services, SLAs, implementation support, and case studies.
* Denis will support the visual design, while Piyush will provide technical and website implementation guidance.
* Community contributors are expected to prepare the initial content.

### Blog and AI Improvements

* Joe proposed updating older blog posts with FAQs, summaries, keywords, and clearer structure.
* The goal is to improve visibility across search engines and AI tools while preserving relevant existing content.
* Piyush confirmed that blog tags already exist but agreed that FAQs and short summaries could be added.
* Joe also requested Markdown export and options for using documentation in tools such as ChatGPT, Claude, and Perplexity.
* Piyush confirmed that this is technically possible and recommended creating GitHub issues to track the work.

### Closing Remarks

* The immediate priority is publishing accurate Console and Console Air onboarding documentation.
* Longer-term priorities include the GPU page, enterprise page, blog modernization, and AI-friendly documentation tools.
* Contributors were encouraged to submit website issues and feature requests through GitHub.
