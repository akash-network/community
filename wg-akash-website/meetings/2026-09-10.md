## Meeting Notes

### Explore, Use Cases & Enterprise Updates

* Denis shared several website and design updates completed over the previous week, including significant changes to the **Explore** section.
* A new **Use Cases** index has been introduced to better organize the different audiences and applications supported by Akash.
* Existing Universities and Startups pages, previously located within the Development navigation, have been moved into the broader Use Cases structure.
* Additional use cases now include **AI Product Engineering** and **Compute Providers**, giving each audience a more dedicated website experience.
* The new **Enterprise** page is also live, with Joe having supported the development of its content.
* The broader objective is to organize Akash website content around specific audiences and practical applications rather than leaving relevant pages distributed across unrelated navigation sections.

### Comparison & Partner Program Pages

* New comparison pages have gone live following several months of development.
* The website now includes dedicated comparisons between **Akash and RunPod, Lambda, AWS, and Heroku**.
* The comparison pages are intended to explain Akash's positioning relative to alternative cloud and compute platforms.
* A new **Partner Program** page is also live, providing information for community members, companies, and ecosystem participants interested in contributing to the open cloud.
* The page outlines different partnership opportunities, provides additional resources, and connects visitors with the Ecosystem Grants program.
* The Partner Program page also includes the Cloudmos Deploy story as an example of ecosystem participation and its eventual acquisition by Overclock.

### Student Ambassadors & Community Contributions

* A minor but important update was completed on the Student Ambassador page.
* A new **Explore Ambassador Contributions** call to action now directs visitors to the Community Contributions section.
* Community Contributions includes a dedicated Student Ambassadors category where ambassador-created articles, tutorials, guides, and other educational materials can be discovered.
* The related website issue has been completed and closed.

### Compute Providers & Website UI

* Denis identified several older website pages that still require visual and structural improvements.
* The **Compute Providers** page is one of the next pages planned for additional polishing.
* Planned changes include improvements to the provider cards and network capacity presentation.
* Denis has already designed the replacement network capacity component, based on the version currently used on the homepage.
* The change is expected to be relatively small because the required design component already exists.
* Additional untouched or older pages will gradually be revisited to improve visual consistency across the website.

### AKT, Validators & Architectural Overview

* Previously agreed navigation changes for the **AKT token** and **Akash Validators** pages have now been implemented.
* Both sections have been moved away from the primary dropdown navigation and are now accessible through the website footer.
* Styling and user-interface improvements were also applied to these pages.
* The previous network overview page has been restructured and renamed **Architectural Overview**.
* The new page explains how Akash works using a more structured and interactive presentation.
* It includes a deployment flow illustrating how a user starts with an SDL, creates a deployment, enters the marketplace, accepts provider bids, and ultimately establishes an active lease.
* Existing technical information from the previous page has been retained but reorganized and supported with improved UI elements.

### Roadmap & Open PRs

* Tyler highlighted ongoing work to refresh the Akash roadmap following community feedback raised during the previous Steering Committee meeting.
* Members of the Core Engineering and Console teams have been updating roadmap items that can be tracked through GitHub and the public website.
* Tyler noted that additional work is still required before the roadmap refresh is fully complete.
* Denis confirmed that relevant PRs are already open and awaiting review.
* The underlying content has been approved, and remaining work primarily involves review and website integration.
* Denis assigned the pending items for review during the meeting, with the expectation that the remaining roadmap issue can be closed once the changes are reviewed and published.

### Closing Remarks

* Tyler thanked Denis for presenting the recent website and design changes.
* The Website Working Group will continue reviewing documentation changes alongside broader website improvements.
* Community members interested in contributing were encouraged to participate through the Website Working Group Discord channel.
* Contributors were also invited to attend future bi-weekly meetings and propose website, documentation, content, or design improvements.
* The next Website Working Group session is expected to take place in two weeks.
