## Meeting Notes

### Opening Remarks & Support Repository Updates

* Tyler Wright welcomed attendees and explained that the Support SIG serves as the primary forum for discussing support-related issues across the Akash Network.
* The **Support Repository** continues to be the central location for issues relating to the Akash blockchain, provider services, node software, and core infrastructure.
* Console API users were reminded that API-specific issues should be submitted through the dedicated Console repository.
* Tyler encouraged community members to actively participate by commenting on GitHub issues, proposing solutions, and collaborating with the Core Engineering team.
* Community pull requests continue to be reviewed, with several community contributions expected to be included in the next provider release.

### Issue Triage & Community Contributions

* Scott Carruthers reported that, for the second consecutive month, there were **no issues awaiting triage**.
* The absence of untriaged issues reflects improvements in the issue management workflow rather than manual cleanup before the meeting.
* New issues are now being categorized correctly at creation, assigned appropriate labels, and routed directly to the responsible engineering teams.
* The improved workflow has significantly reduced issue backlog and accelerated response times.
* Scott encouraged contributors to continue discussing implementation ideas with the Core Engineering team before beginning work on larger community contributions.
* Tyler reiterated that developers interested in contributing to the node, provider, or Console projects can coordinate through GitHub issues, Discord, and the Support SIG channel.
* Technical contributors may also qualify for community bounties after discussing implementation plans with the engineering team.

### Upcoming Provider & Network Releases

* Tyler shared that a new provider release is expected shortly, combining both Core Engineering improvements and community-submitted enhancements.
* Providers were encouraged to monitor official announcements and upgrade promptly once the release becomes available.
* Community Provider Console users will receive upgrade guidance and documentation to simplify the migration process.
* Scott outlined several important infrastructure updates scheduled over the coming weeks.
* A new network upgrade will be required to support changes to the Burn-Mint Equilibrium pricing oracle following backend updates within the Pyth Network.
* The upgrade will primarily introduce updated smart contracts required for the revised oracle infrastructure.
* Scott confirmed that these activities are expected to take place over the next few weeks.

### Provider Feature Roadmap

* Scott announced that the upcoming provider release will introduce support for **Trusted Execution Environment (TEE) confidential computing**, enabling confidential compute workloads on the Akash Network.
* Support for **InfiniBand networking** will also be included, allowing GPUs located on separate physical hosts to communicate more efficiently for distributed AI workloads.
* These capabilities represent significant infrastructure improvements for high-performance GPU deployments and AI applications.
* Additional details regarding these features will be shared during the upcoming Provider SIG meeting.

### Community Support Trends

* Rodri R reported that most recent community support requests involve provider setup and installation issues.
* The majority of reported problems were traced to deployment or configuration mistakes rather than software defects.
* Community members continue requesting updates regarding the provider verification and audit process.
* Rodri also highlighted a recent scam attempt within Discord where malicious users shared fake airdrop images and fraudulent links.
* The incident raised questions about improving Discord moderation and automated scam detection.
* Tyler noted that the Core Engineering team continues to improve the provider verification process to make audits more automated, scalable, and accessible for providers.

### Console Redesign & Onboarding Improvements

* Tyler announced that the Akash Console is undergoing a significant redesign together with improvements to the onboarding experience.
* Existing documentation and getting-started guides will require updates once the redesign is released.
* Contributors interested in technical writing, documentation, React, or TypeScript development were encouraged to participate.
* The redesigned onboarding flow will undergo additional usability testing during an upcoming hackathon.
* Community members from Akash Club have already participated in early testing and provided valuable feedback.
* The hackathon will provide an opportunity to observe how first-time users interact with the redesigned Console experience before its broader release.
* Tyler explained that documentation updates will become an important part of the wider go-to-market strategy following the redesign.

### Community Contribution Opportunities & Closing Remarks

* Tyler encouraged developers interested in Go, React, and TypeScript to become more involved in Akash's open-source ecosystem.
* Contributors were reminded that implementation discussions should begin through GitHub issues before development starts.
* Community members were encouraged to remain active within Discord, particularly the Support SIG channel, between monthly meetings.
* Tyler reminded attendees about the Economics SIG later that day and the upcoming Provider SIG meeting the following week.
* Members were asked to watch Discord for announcements regarding provider releases, Console improvements, and other technical updates.
* The meeting concluded with thanks to contributors, Core Engineering members, and the wider Akash community for helping maintain a responsive support process.
