## Meeting Notes

### Support Triage & Home Node

* The Support repository had only one issue awaiting triage, related to Home Node.
* Because Home Node currently uses a private Overclock repository, community members cannot directly submit issues there.
* The team agreed to leave the existing issue in the Support repository and escalate it through the Home Node Beta Discord channel.
* Tyler will discuss a longer-term support funnel for Home Node with the team, potentially similar to the support process used for Akash ML.
* All other Support repository issues were confirmed to be assigned to the appropriate engineers and repositories.

### Provider v0.16.4

* The Core team is rolling out **Provider v0.16.4**, introducing native ARM64 provider support.
* Deployers will be able to specify ARM64 or AMD64 CPU architecture directly within the SDL and bidding process.
* AMD64 remains the default, allowing existing templates and SDLs to continue working without modification.
* The release also introduces additional HTTP buffer configuration options needed by some LLM deployments and AI workloads.
* The Core team is validating the release across sandbox and managed providers before asking community providers to upgrade.

### BME & Console Updates

* Additional BME resilience work is underway, including secondary pricing sources.
* These changes are expected to require a network upgrade within the following weeks.
* Tyler also highlighted upcoming Console UX/UI improvements and roadmap proposals from the product team.
* Work is underway to explore additional Console functionality, including organization-level capabilities and broader product improvements.

### Community Support

* Joe encouraged users to submit support requests through the Akash website ticketing system when an issue requires ongoing troubleshooting or follow-up.
* Discord remains available for support, but longer technical conversations can become difficult to track there.
* Rodri reported several routine provider questions but no unusual or significant support problems.
* Community members can continue using GitHub issues, SIG Support, Discord, and the website ticketing system depending on the nature of the issue.

### Closing Remarks

* Providers were advised to watch for the official v0.16.4 upgrade announcement once Core team testing is complete.
* Community members were encouraged to raise support issues between meetings through GitHub, SIG Support, or the website ticketing system.
* No additional support issues were raised during the meeting.
