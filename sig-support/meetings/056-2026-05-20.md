### Provider Bid Script Issue

* Scott Carruthers reviewed a reported issue involving the Akash Provider bid shell script
* Explained that custom bid scripts are loaded into memory when an Akash Provider starts
* Noted that providers use custom bid scripts to define pricing strategies for:
  * GPUs
  * CPUs
  * Storage
* Explained that the reported issue suggests certain pricing values defined in the bid script may not be taking effect
* Highlighted that if the issue were widespread, it would represent a high-priority provider problem
* Explained that providers could potentially submit bids using pricing different from their configured pricing strategy
* Noted that the issue currently appears to be an edge case rather than a widespread network problem
* Confirmed that the Core Team had not previously encountered or successfully replicated the issue
* Emphasized that the inability to reproduce the issue does not mean the reported problem is invalid
* Explained that the first investigation step will be to deploy a test provider and attempt to reproduce the reported behavior
* Assigned the issue to Zeke for initial provider-level investigation
* Clarified that the initial investigation will focus on reproducing the issue before deeper code-level analysis
* Confirmed that additional code investigation may be required if the behavior can be replicated

### Akash Console Wallet Changes

* Tyler Wright clarified the recent changes to Akash Console
* Explained that Akash Console is now designed exclusively for managed wallet users
* Announced that Console Air is the dedicated solution for users who prefer crypto wallets and self-custody
* Explained that historically Akash Console served both:
  * Managed wallet users
  * Self-custodied crypto wallet users
* Highlighted that these audiences have significantly different needs and onboarding expectations
* Explained that the separation was introduced as Akash Network continues attracting more businesses and enterprise users
* Noted that the decision had previously been discussed during SIG Clients
* Confirmed that an Akash Enhancement Proposal also documents the product separation

### Console Air

* Tyler Wright explained that Console Air now operates as a standalone solution
* Confirmed that Console Air has its own GitHub repository
* Explained that Console Air is intended for self-custodied crypto wallet users
* Clarified that Console Air remains open source and can be independently deployed
* Confirmed that Console Air-related issues should be submitted to its dedicated repository
* Joe Deng announced that Shimpa from Europlots had deployed a hosted Console Air installation
* Confirmed that the hosted installation had been pinned in the Akash Discord for easy community access
* Encouraged users requiring Console Air access to reference the pinned Discord resource
